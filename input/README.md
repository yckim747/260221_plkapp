# input 폴더 사용법

## 요구사항 파일 작성 규칙

파일명: `{페이지명}.md` (예: `booking_main.md`, `my_reservation.md`)

## 템플릿

```markdown
# 페이지명

## 페이지 설명
- 한 줄 요약

## 포함 섹션
- [ ] 헤더
- [ ] 가로 스크롤 달력
- [ ] 검색바
- [ ] 지역 탭메뉴
- [ ] 카드 리스트
- [ ] 상세검색 팝업
- [ ] 팝업 달력
- [ ] Alert/Confirm 팝업
- [ ] 로딩 화면
- [ ] 퀵메뉴
- [ ] 예약 Hidden Form

## 상세 요구사항
- 구체적인 동작, 데이터, 조건 등 기술

## 참고 자료
- 피그마 URL, 스크린샷 경로, 기존 페이지 참고 등
```

## 사용 방법

1. 이 폴더에 요구사항 .md 파일을 작성합니다
2. Claude에게 `input/{파일명}.md 개발해줘` 라고 요청합니다
3. `output/{페이지명}/` 폴더에 결과물이 생성됩니다
