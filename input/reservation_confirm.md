# 예약 확인 페이지 (예약하기)

## 페이지 설명
- 메인 리스트에서 티타임 클릭 후 진입하는 예약 확인/결제정보 입력 페이지
- 본인 방문 / 위임 두 가지 예약 유형에 따라 다른 폼 구성

## 포함 섹션
- [x] 헤더 (예약하기 타이틀 + 뒤로가기)
- [x] 예약 정보 요약 (골프장명, 날짜, 시간, 코스, 그린피)
- [x] 예약 유형 선택 (본인 방문 / 위임)
- [x] 본인 방문 폼 (결제방법, 결제자 선택, 동반자 정보)
- [x] 위임 폼 (위임자 정보, 결제방법, 결제자 선택)
- [x] 하단 고정 예약 요청 버튼
- [x] Alert/Confirm 팝업
- [x] 로딩 화면

## 상세 요구사항

### 예약 유형 탭
- 본인 방문 / 위임 택 1 (pill 버튼)
- 기본 선택: 본인 방문
- 탭 전환 시 해당 폼 show/hide

### 본인 방문 흐름
- 결제 방법: 오픈카드 / 현장결제(페이백) 택 1
- 결제자 선택: 내가 결제(전액) / 동반자 나눠 결제 택 1
- 동반자 나눠 결제 선택 시:
  - 동반자 정보 입력 폼 슬라이드 노출
  - 이름, 연락처, 결제금액 입력
  - 동반자 추가 버튼 (최대 3명)
  - 결제금액 합계 = 그린피 총액 검증

### 위임 흐름
- 위임자 정보 입력 (이름, 연락처) - 필수
- 결제 방법: 오픈카드 / 현장결제(페이백) 택 1
- 결제자 선택: 회원 결제(전액) / 위임 결제(전액) 택 1

### 유효성 검증
- 결제 방법 필수 선택
- 결제자 유형 필수 선택
- 위임 시 위임자 이름/연락처 필수
- 동반자 나눠 결제 시 동반자 정보 필수, 금액 합계 검증
- 연락처: 숫자만, 10~11자리
